# Oreedo

Mesin pembuat **prompt AI** dan **PRD** yang berjalan sepenuhnya di browser.
Isi form singkat, dapatkan prompt atau `PRD.md` + `TASKS.md` yang siap tempel
ke ChatGPT, Claude, Gemini, DeepSeek, atau GLM.

- Tanpa framework, tanpa build tool, tanpa backend.
- Tanpa API key. Tidak ada data yang dikirim ke server.
- Draf isian disimpan di `localStorage` (dibungkus `try/catch`).
- Siap dipasang di GitHub Pages, termasuk saat berada di subfolder repo.
